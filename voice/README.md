# Komunikaty głosowe aplikacji Reporter

Aplikacja pobiera te pliki przy starcie przez `raw.githubusercontent.com`
(release assets NIE działają — GitHub nie wysyła dla nich nagłówków CORS,
więc przeglądarka w aplikacji blokuje pobieranie).

Podmiana nagrania = podmiana pliku w tym folderze. **Nie wymaga wydawania
nowej wersji aplikacji** — zmiana działa u graczy po następnym uruchomieniu.
Nazwy plików muszą zostać bez zmian.
